terminal 에서 특정 경로로 이동하는 명령어 'cd ~' 특정 파일 경로로 이동 후 .java 파일 컴파일 하는 명령어 'javac 파일이름' .java 파일 실행하는 명령어 'java 파일이름' -> java는 파일을 컴파일할 경우 사람이 이해할 수 있는 소스코드를 JVM(자바가상머신)이 실행할 수 있도록 바이트코드(.class 파일)로 변환함. 바로 실행할 경우 .class 파일 생성하지 않고 그 안에서 컴파일과 실행이 한번에 이루어짐.

문자 타입은 ''로 감싸주고, 문자열 타입은 ""로 감싸줘야 됨(이때는 유니코드로 변환하지 않음). 즉, 작은따옴표와 큰따옴표의 구분이 필요.
