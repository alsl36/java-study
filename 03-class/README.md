Class : 설계도, Instance : 설계도로 만들어진 객체
class는 생성자, 필드, 메소드 3가지 요소로 이루어짐

정적 메소드 안에서는 인스턴스 필드나 인스턴스 메소드를 사용할 수 없음. this도 사용 불가능.

final 필드에 초기값을 줄 수 있는 방법은 1. 필드 선언 시에 초기값 대입 2. 생성자에서 초기값 대입.

static final 필드로 상수 정의 가능.

<접근 제한자>
public : 제한 없음
protected : 같은 패키지 혹은 자식 객체만
(default) : 같은 패키지
private : 객체 내부

필드를 private 제한자로 설정 후 Getter 와 Seter 메소드를 통해서만 접근하도록 하여 필드에 대한 직접적인 접근을 제한 할 수 있음.
